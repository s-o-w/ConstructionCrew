# HOME

Entry point for this vault. Navigation only -- content lives in the notes this
page points at, never on this page.

## Where things live

| What | Where |
|---|---|
| Project nodes and their Vision / Architecture / Roadmap / Status docs | `Notes/<Project>/` |
| Permanent notes, one evergreen concept per file | `Notes/` (flat) |
| Agent-executable implementation plans | `Plans/<Project>/<Feature>/` |
| Weekly logs, one per week | `Journal/YYYY-Www.md` |
| Ontology, vocabularies, and the generated graph | `AI/graph/` |
| Vault conventions and templates | `VAULT-META/` |
